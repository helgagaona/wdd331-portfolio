  src: url("/fonts/RobotoFlex-VariableFont.ttf")
    format("truetype");
  font-weight: 100 1000;

}

Custom Axes

Custom axes do not have their own CSS property, so they use font-variation-settings. 

font-variation-settings:
  "GRAD" 50,
  "XTRA" 500;

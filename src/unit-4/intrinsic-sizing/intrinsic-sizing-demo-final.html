Intrinsic Sizing Keywords

Change the controls below and watch how the content changes the size of each grid column.

1. min-content: label column

The first column becomes as narrow as possible while still fitting its longest unbreakable word.

min-content 1fr
Name
Alex Chen
Phone Number
WDD 331
Qty
2

grid-template-columns: min-content 1fr;

2. max-content: status badge column

The first column grows enough to keep the badge on one line.

max-content 1fr
Done
Publish Unit Index
In Review
Review Grid Prove Rubric
Draft
Update Color Token Sheet

grid-template-columns: max-content 1fr;

3. fit-content(): capped tag column

The column grows with the content, but it stops growing at the selected maximum width.

fit-content(180px) 1fr
